## Structure

```
NOUN_PHRASE = [ GENITIVE_PHRASE ], NOUN, SPACE, CASE_DETERMINER ;

GENITVE_PHRASE = NOUN, SPACE, GENITIVE_DETERMINER, SPACE ;

SPACE = " " ;

GENITIVE_DETERMINER = DETERMINER, GENITIVE_CASE ;
CASE_DETERMINER = DETERMINER, ALL_CASES_EXCEPT_GENITIVE ;

GENITIVE_CASE = "nä" ;
ALL_CASES_EXCEPT_GENITIVE = "" | "ashi" ;
ALL_CASES = GENITIVE_CASE | ALL_CASES_EXCEPT_GENITIVE ;

DETERMINER = "" | "shu" | "ri" | "kú" | "ru" 
           | "ti" | "sä" | "wu" | "u" | "ta" ;
```
